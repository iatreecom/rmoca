# 기능 목록

Obsidian의 마크다운 기능과 Samsung Notes의 노트·필기 기능을 정리하고, rmoca에서 어떻게 구현했는지 표시합니다.

- ✅ 구현됨
- ⏳ 아직 구현하지 않음 (이유 포함)

rmoca는 **Obsidian과 같은 문법과 폴더 규칙**(`[[링크]]`, `#태그`, 콜아웃, `.trash`, `Templates/`)을 따릅니다. 그래서 동기화하는 Git 저장소를 그대로 Obsidian 보관함(vault)으로 열 수 있습니다.

## Obsidian — 마크다운

| 기능 | 상태 | rmoca에서 |
|---|---|---|
| 위키링크 `[[메모]]`, 별칭 `[[메모\|표시 이름]]`, 제목 `[[메모#제목]]` | ✅ | 누르면 해당 메모로 이동. 없는 메모면 새로 만들지 물어봄 |
| 임베드 `![[메모]]`, `![[그림.svg]]` | ✅ | 다른 메모 내용이나 그림을 카드로 보여줌 (2단계까지) |
| 백링크 | ✅ | 메모 아래에 이 메모를 링크한 메모 목록 |
| 태그 `#태그`, 중첩 태그 `#일/분기` | ✅ | 사이드바·태그 시트에서 목록, 태그별 메모 화면 |
| 속성 (YAML frontmatter) | ✅ | 메모 위에 속성 카드, `tags:` 도 태그로 인식 |
| 콜아웃 `> [!note]`, `> [!warning]-` | ✅ | 종류별 색·아이콘(note, tip, warning, danger, bug, example, quote 등 13종), 접기/펼치기 |
| 체크리스트 `- [ ]` | ✅ | 읽기 화면에서 눌러서 체크. 중첩 목록도 정확한 줄을 수정 |
| 형광펜 `==텍스트==` | ✅ | |
| 취소선, 표, 자동 링크 (GFM) | ✅ | |
| 주석 `%%숨김%%` | ✅ | 읽기 화면에서 숨김 |
| 수식 `$...$`, `$$...$$` (LaTeX) | ✅ | |
| 코드 블록 문법 강조 | ✅ | 190여 개 언어, 라이트/다크 테마 |
| 목차 (아웃라인) | ✅ | 제목 목록에서 눌러 해당 위치로 이동 |
| 빠른 이동 (Ctrl/⌘+K) | ✅ | 퍼지 검색, 없으면 새 메모 만들기 |
| 일일 노트 | ✅ | `Daily/yyyy-MM-dd.md`, `Templates/Daily.md` 가 있으면 사용 |
| 템플릿 | ✅ | `Templates/` 폴더, `{{title}}`, `{{date}}`, `{{time}}` |
| `[[` 입력 시 메모 이름 자동완성 | ✅ | |
| 목록 자동 이어쓰기 (Enter) | ✅ | 빈 항목에서 Enter 하면 목록 종료 |
| 이름 바꾸기·이동 시 링크 자동 수정 | ✅ | 상대 경로 링크와 이미지 링크 |
| 휴지통 `.trash` | ✅ | |
| 단어·글자 수 | ✅ | |
| 그래프 뷰 | ⏳ | 메모 간 링크 데이터는 이미 있음. 시각화만 남음 |
| Mermaid 다이어그램 | ⏳ | Flutter용 렌더러가 없어 별도 구현 필요 |
| 각주 `[^1]` | ⏳ | 렌더러 지원이 불완전 |
| 블록 참조 `^id`, 라이브 프리뷰, 캔버스, 플러그인 | ⏳ | 규모가 큰 기능 |

## Samsung Notes — 필기와 정리

| 기능 | 상태 | rmoca에서 |
|---|---|---|
| 펜 종류 | ✅ | 펜, 만년필, 연필, 붓, 형광펜(아래 글씨가 비치게 겹침). 펜마다 굵기 따로 기억 |
| 필압 | ✅ | 스타일러스 압력 반영, 손가락·마우스는 속도로 흉내 |
| 지우개 | ✅ | 획 지우개, 부분 지우개(선을 잘라냄), 크기 조절, 스타일러스 뒤쪽 지우개 |
| 올가미 선택 | ✅ | 이동, 크기 조절(손잡이, Shift로 비율 해제), 색 바꾸기, 복제, 삭제 |
| 도형 자동 보정 | ✅ | 직선, 삼각형, 사각형, 원/타원. 켜 두거나, 끝에서 펜을 잠시 멈추면 보정 |
| 종이 스타일 | ✅ | 무지, 줄, 모눈, 점. SVG 패턴으로 저장돼 GitHub에서도 보임 |
| 색상 | ✅ | 프리셋 12색, 색상·채도·밝기·HEX 직접 선택, 최근 색 |
| 확대/축소·이동 | ✅ | 두 손가락 핀치, Ctrl+휠, 트랙패드, 가운데 버튼 드래그, 화면에 맞추기 |
| 손바닥 무시 | ✅ | "펜으로만 그리기": 손가락은 이동만 |
| 실행 취소/다시 실행 | ✅ | Ctrl/⌘+Z, Shift로 다시 실행 |
| 글과 그림을 한 노트에 | ✅ | 그림을 메모 안에 `<svg>` 로 넣거나 별도 `.svg` 파일로 링크. GitHub 웹 화면은 `.md` 안의 `<svg>` 를 표시하지 않으므로, GitHub에서 볼 일이 많다면 SVG 파일 방식이 낫습니다 |
| 폴더와 하위 폴더 | ✅ | 트리 사이드바, 이동, 이름 바꾸기 |
| 폴더 색 | ✅ | 동기화됨 |
| 즐겨찾기 | ✅ | 목록 맨 위 + 즐겨찾기 모아보기. 동기화됨 |
| 정렬 | ✅ | 최근 수정, 오래된 순, 이름순, 이름 역순 |
| 휴지통 | ✅ | 30일 보관 후 자동 삭제, 복원, 실행 취소 |
| 여러 개 선택 | ✅ | 길게 누르기 → 즐겨찾기·이동·삭제 |
| 카드/목록 보기, 썸네일 | ✅ | 그림이 있는 메모는 그림 썸네일 |
| 텍스트 상자, 이미지 삽입 | ⏳ | 그림 데이터 형식 확장 필요 |
| 노트 잠금 (암호) | ⏳ | Git에 올라가는 내용의 암호화 방식 설계 필요 |
| 음성 녹음, PDF 주석 | ⏳ | 바이너리 파일 동기화 필요 |
| 필기 인식 (손글씨 검색) | ⏳ | 기기별 인식 엔진 필요 |
| PDF·이미지로 내보내기 | ⏳ | |

## rmoca 고유 기능

- **Git 동기화**: 오프라인 우선, 3-way 비교, 충돌 시 내용을 잃지 않는 사본 저장, 동기화 1회 = 커밋 1개
- **즐겨찾기·폴더 색 병합**: `.rmoca/meta.json` 은 충돌 사본 대신 항목별로 최신 값을 합침
- **화면 설정**: 라이트/다크/시스템, 강조색 6종

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl/⌘ + K | 빠른 이동 |
| Ctrl/⌘ + N | 새 메모 (목록 화면) |
| Ctrl/⌘ + E | 편집 ↔ 읽기 |
| Ctrl/⌘ + B / I | 굵게 / 기울임 |
| Ctrl/⌘ + Z, Shift + Ctrl/⌘ + Z | 실행 취소 / 다시 실행 (그림) |
| P / E / L / H | 펜 / 지우개 / 올가미 / 이동 (그림) |
| Delete, Backspace | 선택한 획 삭제 (그림) |
| Ctrl + 마우스 휠 | 확대/축소 (그림) |
