# 기능 목록

Obsidian의 마크다운 기능과 Samsung Notes의 노트·필기 기능을 정리하고, rmoca에서 어떻게 구현했는지 표시합니다.

- ✅ 구현됨
- ⏳ 아직 구현하지 않음 (이유 포함)

rmoca는 **Obsidian과 같은 문법과 폴더 규칙**(`[[링크]]`, `#태그`, 콜아웃, `.trash`, `Templates/`)을 따릅니다. 그래서 동기화하는 Git 저장소를 그대로 Obsidian 보관함(vault)으로 열 수 있습니다.

## 쉬운 편집 (블록 모드)

마크다운 문법을 몰라도 쓸 수 있는 편집 방식입니다. 메모 화면 위쪽에서 **읽기 / 쉬운 편집 / 마크다운** 을 고릅니다.

| 기능 | 설명 |
|---|---|
| 블록 단위 편집 | 메모가 렌더링된 상태 그대로 보이고, 문단·제목·목록·표·수식 등 블록을 누르면 그 부분만 편집 |
| 서식 버튼 | 굵게, 기울임, 취소선, 형광펜, 코드, 수식, 메모 링크, 제목, 목록, 체크리스트, 인용 |
| 블록 메뉴 | 빈 줄에서 `/` 또는 **+ 블록**: 제목 1–3, 목록, 체크리스트, 인용, 구분선, 콜아웃 5종, 접기, 표, 코드, 수식, 순서도·시퀀스·파이·간트 차트, 사진·카메라, 손글씨 그림, 메모 링크·넣기, 태그, 오늘 날짜, 현재 시각. 검색 가능 |
| 표 편집기 | 칸에 직접 입력, 행·열 추가/삭제, 열 정렬(왼쪽·가운데·오른쪽) |
| 블록 메뉴 (길게 누르기) | 위·아래에 추가, 위·아래로 이동, 복제, 삭제, 종류 바꾸기(텍스트↔제목↔목록↔체크리스트↔인용) |
| 이어 쓰기 | 빈 줄에서 Enter 하면 블록이 끝나고 새 블록 시작, 목록은 자동으로 이어짐 |
| 문법 도움말 | ? 버튼: 마크다운 문법과 실제 모양을 나란히 보여주고, 누르면 삽입 |

편집한 블록만 바뀌고 나머지 원문(빈 줄, 들여쓰기 등)은 그대로 유지됩니다.

## 태블릿

- **분할 보기**: 가로 1100px 이상(태블릿 가로, 데스크톱)에서는 왼쪽 목록, 오른쪽 메모. 메모 안의 링크도 오른쪽에서 열림. 목록 위 버튼으로 켜고 끔
- **글자 크기**: 메모 메뉴 → 글자 크기, 설정, 또는 Ctrl/⌘ + / - / 0 (80–160%)
- **펜**: 필압, 펜으로만 그리기(손바닥 무시), 스타일러스 뒤쪽 지우개
- **하드웨어 키보드** 단축키 지원

## Git 서버

| 방식 | 대상 |
|---|---|
| GitHub (API) | github.com, GitHub Enterprise |
| Git 서버 (HTTPS) | GitHub, GitLab, Gitea·Forgejo·Codeberg, Bitbucket, Azure DevOps, `git http-backend`, NAS 등 git smart HTTP를 지원하는 모든 서버 |

- git 프로토콜을 앱이 직접 처리하므로 기기에 git이 없어도 됩니다 (iOS·Android 포함).
- 최신 커밋만 얕게 받고, 이후에는 바뀐 객체만 받습니다 (델타 압축 지원).
- 자체 서명 인증서 허용, 커밋 작성자 지정.

## 오프라인

- 메모(`.md`), 그림(`.svg`), 첨부 이미지(png·jpg·gif·webp·bmp)가 모두 기기에 저장되고 Git과 동기화됩니다.
- 메모가 쓰는 **원격 이미지(http/https)는 온라인일 때 미리 내려받아** 앱 저장 공간에 보관합니다. 앱 시작, 동기화 후, 네트워크가 돌아왔을 때 아직 없는 것만 받습니다. 그래서 한 번도 열어보지 않은 메모의 이미지도 오프라인에서 보입니다.
- 수식 글꼴, 코드 강조, Mermaid 렌더러는 앱에 들어 있어 인터넷이 필요 없습니다.
- 받아둔 적 없는 원격 이미지를 오프라인에서 열면 "오프라인이라 불러올 수 없음" 표시가 나옵니다.

## rmoca 고유 기능

- **Git 동기화**: 오프라인 우선, 3-way 비교, 충돌 시 내용을 잃지 않는 사본 저장, 동기화 1회 = 커밋 1개
- **즐겨찾기·폴더 색 병합**: `.rmoca/meta.json` 은 충돌 사본 대신 항목별로 최신 값을 합침
- **화면 설정**: 라이트/다크/시스템, 강조색 6종, 글자 크기, 기본 편집 방식
